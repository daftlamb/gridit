How to use Grid It

Paper

Choose a preset (A4, A3, Letter…) or enter custom dimensions. Switch between mm / px / pt using the Unit toggle.

Margins

Set top, bottom, left, and right margins. The margin guide is shown as a dashed rectangle in the preview.

Columns & Rows

Use the sliders to set the number of columns / rows and the gutter (gap) between them. Try the Classic Grid presets for historical references.

Colors

Use the Colors section to change the color of column guides, row guides, and margin guides. Colors are reflected live in the preview and in the exported SVG.

Export

Click Download SVG or press O to export. The SVG uses transparent fills with colored strokes — ready to place in Figma, Illustrator, InDesign, etc.

Shortcut

Press O to instantly export the current grid as SVG.

About

Grid It is a graphic design grid generator inspired by the Swiss typographic tradition. Define paper size, margins, columns and rows — then export a clean SVG for use in any design tool.

Classic presets reference the work of Josef Müller-Brockmann, Jan Tschichold and the Van de Graaf canon.

Press O to export SVG.
