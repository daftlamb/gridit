# Grid It

> Design grids, exported clean.

Grid It is a graphic grid generator for designers. Configure columns, rows, margins, and gutters — then export as SVG or PNG, ready to drop into Figma, Illustrator, or InDesign.

---

## What it does

Set up a custom grid with full control over structure and color. The live preview updates instantly. When you're ready, export a transparent-background SVG with colored strokes — no rasterization, no scaling artifacts.

---

## Features

- **Column & row grids** — classic layout grids with custom counts and gutters
- **Margin guides** — configurable margins on all sides
- **Custom colors** — independent colors for column, row, and margin guides
- **Live preview** — changes reflect instantly in the canvas
- **Custom fonts** — type any Google Font name to preview layout with real type
- **Export SVG** — press `O` or click Download SVG; transparent fills, colored strokes
- **Export PNG** — raster export with transparent background
- **Keyboard shortcut** — `O` to export instantly

---

## Export

The SVG uses transparent fills with colored strokes — paste directly into Figma, Illustrator, or InDesign as a design guide layer.

---

## Tech

- Pure Canvas 2D + SVG generation
- No framework. No build step. One HTML file.
