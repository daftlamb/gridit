# Grid It

> Precise layout grids for real artboards.

Grid It is a focused layout grid generator for designers. Configure columns, rows, margins, gutters, and reference images, then export clean SVG or PNG guides for Figma, Illustrator, InDesign, or print.

---

## What it does

Set up a custom artboard grid with full control over structure and color. The live preview updates instantly, reference images can be traced without distortion, and SVG export keeps guides organized in named layers.

---

## Features

- **Column & row grids** - classic layout grids with custom counts and gutters
- **Margin guides** - configurable margins on all sides
- **Custom colors** - independent colors for column, row, and margin guides
- **Live preview** - changes reflect instantly in the canvas
- **Reference image** - trace uploaded images with fit, fill, original-size, and center controls
- **Custom fonts** - type any Google Font name to preview layout with real type
- **Export SVG** - press `O` or click Download SVG; named layers for artboard, columns, rows, and margins
- **Export PNG** - raster export for quick previews and sharing
- **Keyboard shortcut** - `O` to export instantly

---

## Export

The SVG uses clean guide geometry and named groups. Paste it directly into Figma, Illustrator, or InDesign as a design guide layer.

---

## Tech

- Pure Canvas 2D + SVG generation
- No framework. No build step. One HTML file.
